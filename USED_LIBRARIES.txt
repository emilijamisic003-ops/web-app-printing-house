==================================================
NAPOMENE I MOGUĆI PROBLEMI
==================================================

1. image-size je stvarno importovan u backend kodu, ali se nalazi samo u
   root package.json. To nije potpuno nedeklarisan paket, ali izolovana
   instalacija samo backend foldera neće instalirati ovu zavisnost.
   U postojećem rasporedu može se pronaći u root node_modules.

2. Backend sada ima lokalni typescript 5.9.3 u devDependencies i koristi
   target ES2022. Nije potrebna globalna instalacija TypeScript kompajlera.

3. mongodb je prisutan, ali verovatno nekorišćen kao direktna zavisnost
   aplikacije: kod pristupa bazi preko mongoose. Sam MongoDB drajver se
   ipak koristi posredno kroz Mongoose. Ovo nije tvrdnja da drajver nije potreban.

4. baseline-browser-mapping nema direktne importe u aplikaciji, ali se
   koristi posredno kroz browserslist u Angular build lancu.

5. Prettier podešavanja postoje u frontend/package.json, ali prettier nije
   deklarisan kao paket i nema npm skripte koja ga pokreće. Zbog toga nije
   naveden kao potvrđena biblioteka projekta.

6. Brevo je spoljašnji email servis, a ne instaliran npm paket u ovom
   projektu. backend/src/utils/brevo-mail.ts koristi ugrađeni fetch za
   HTTPS zahtev. Ne koriste se Brevo SDK, axios ili nodemailer.
   fetch, FormData, File, localStorage i JSON nisu zasebni npm paketi.

7. Angular podmoduli kao @angular/common/http, @angular/core/testing i
   @angular/core/rxjs-interop deo su već navedenih Angular paketa,
   a ne dodatne biblioteke koje treba posebno instalirati.

Pregled je statički: status upotrebe zasnovan je na kodu i konfiguraciji.
Nijedan paket nije instaliran/uklonjen i kod aplikacije nije menjan.
